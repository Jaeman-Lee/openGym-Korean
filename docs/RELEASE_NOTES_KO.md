## openGym 한국어판 1.2.9-ko.1

openGym 1.2.9를 바탕으로 만든 첫 한국어 현지화 릴리스입니다.

### 주요 변경 사항

- 한국 사용자가 자연스럽게 이해할 수 있도록 전체 UI 문구를 다듬었습니다.
- 한국어를 기본 언어로 설정했습니다.
- 국내 헬스 용어에 맞춘 운동명과 한국어 검색을 추가했습니다.
- 기본 밀기·당기기·하체 루틴을 한국어로 제공합니다.
- 운동 설명에서 자주 나타나는 기계 번역 표현을 보정했습니다.
- 원본 앱과 함께 설치할 수 있도록 별도 패키지명을 사용합니다.

### 설치 전 확인

- Android 6.0 이상에서 사용할 수 있습니다.
- APK와 함께 제공되는 `.sha256` 파일로 다운로드 무결성을 확인할 수 있습니다.
- 이 버전은 원작자의 공식 배포판이 아닌 비공식 한국어 현지화 버전입니다.
